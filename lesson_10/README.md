# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
Запустите тесты с генерацией отчета Allure:

bash
pytest --alluredir=./allure-results
Эта команда запустит все тесты и сохранит результаты в директорию ./allure-results.

Инструкция по просмотру сформированного отчета Allure
После завершения тестов, чтобы просмотреть отчет, выполните команду:

bash
allure serve ./allure-results
Эта команда запустит локальный сервер и откроет отчет в браузере.

В отчете Allure вы увидите:

Тест калькулятора (test_calculator.py)

Название теста: Например, Проверка сложения 7 + 8 = 15 с задержкой 45 секунд.

Описание теста: Тест проверяет, что калькулятор корректно выполняет сложение 7 и 8 при задержке вывода результата 45 секунд.

Шаги теста:

Открытие страницы калькулятора.

Установка задержки 45 секунд.

Нажатие кнопок: 7, +, 8, =.

Проверка результата:

Ожидание и получение результата с экрана.

Сравнение результата с ожидаемым 15.

Результат: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.

Тест интернет-магазина (test_shop.py)

Название теста: Например, Оформление заказа из трёх товаров.

Описание теста: Тест проверяет полный сценарий покупки: авторизация, добавление трёх товаров в корзину, оформление заказа и проверка итоговой суммы.

Шаги теста:

Открытие страницы авторизации.

Авторизация пользователем standard_user.

Добавление трёх товаров в корзину.

Переход в корзину.

Переход к оформлению заказа.

Заполнение формы оформления заказа.

Проверка итоговой суммы:

Получение итоговой суммы.

Сравнение итоговой суммы с ожидаемой Total: $58.29.

Результат: Успешное выполнение или ошибка с указанием ожидаемого и фактического значения.
